# Электронная таблица на C++17

Дипломный проект: реализация ядра электронной таблицы (по типу Excel/Google Sheets) на C++. Проект демонстрирует навыки работы с парсингом, графами зависимостей, кэшированием вычислений и объектно-ориентированным проектированием.

## Возможности

*   **Формулы:** Поддержка арифметических выражений (`+`, `-`, `*`, `/`), унарных операторов, скобок и ссылок на ячейки (например, `=A1+B2*2`).
*   **Парсинг:** Использование генератора парсеров ANTLR4 для разбора грамматики формул и построения Абстрактного Синтаксического Дерева (AST).
*   **Реактивность:** Автоматический пересчет значений при изменении данных. Система отслеживает зависимости между ячейками и обновляет только те значения, которые изменились.
*   **Безопасность:**
    *   Обнаружение и предотвращение циклических зависимостей.
    *   Обработка ошибок вычислений: деление на ноль (`#ARITHM!`), некорректные ссылки (`#REF!`), ошибки типов (`#VALUE!`).
*   **Типы данных:** Поддержка текста, чисел (double) и текстовых строк, выглядящих как формулы (экранирование через `'`).
*   **Вывод:** Печать таблицы в виде текста (как введено) и в виде вычисленных значений с автоматическим определением размера печатной области.

## Технологии и стек

*   **Язык:** C++17 (Standard Library, Variants, Optional, Smart Pointers).
*   **Сборка:** CMake (минимальная версия 3.8).
*   **Парсинг:** ANTLR4 (C++ Runtime).
*   **Тестирование:** Встроенный фреймворк unit-тестов (`test_runner_p.h`).

## Структура проекта

Проект модульный и разделен по зонам ответственности:

| Файл | Описание |
| :--- | :--- |
| `common.h` | Базовые структуры (`Position`, `Size`), исключения и интерфейсы (`CellInterface`, `SheetInterface`). |
| `structures.cpp` | Логика конвертации позиций (строка "A1" ↔ координаты `{0,0}`) и форматирования ошибок. |
| `Formula.g4` | Грамматика ANTLR для описания синтаксиса формул. |
| `FormulaAST.h/cpp` | Ядро парсера. Построение AST, узлы дерева (числа, операции, ссылки), логика вычисления выражений. |
| `formula.h/cpp` | Обертка над AST, реализующая интерфейс формулы. |
| `cell.h/cpp` | Реализация ячейки. Использует паттерн **Strategy** (Empty, Text, Formula). Управляет кэшем значений и списками зависимостей/зависимых. |
| `sheet.h/cpp` | Реализация таблицы. Хранит коллекцию ячеек, управляет глобальным состоянием, инициирует пересчет каскада зависимостей. |
| `main.cpp` | Набор интеграционных и юнит-тестов, покрывающих основные сценарии использования. |

## Сборка и запуск

Для сборки проекта вам потребуется установленный **Java Runtime** (для запуска ANTLR) и компилятор C++17.

1.  Убедитесь, что файл `antlr-4.12.0-complete.jar` находится в корне проекта (или укажите путь в `CMakeLists.txt`).
2.  Создайте директорию для сборки:
    ```bash
    mkdir build && cd build
    ```
3.  Запустите CMake и сборку:
    ```bash
    cmake ..
    cmake --build .
    ```
4.  Запустите исполняемый файл `spreadsheet`. Программа автоматически проведет все unit-тесты и выведет результаты в консоль.

## Тестирование

В проекте реализован собственный тест-раннер. В файле `main.cpp` содержатся тесты для проверки:
*   Корректности преобразования координат (A1, Z1, AA1, XFD16384).
*   Арифметики формул и приоритета операций.
*   Работы с ссылками на ячейки.
*   Обработки ошибок (Value, Arithmetic, Ref).
*   Детекции циклических ссылок.
*   Корректности вывода таблицы (`PrintValues`, `PrintTexts`).

## Архитектурные решения

1.  **Кэширование:** Значения ячеек не пересчитываются при каждом обращении. Кэш сбрасывается (`InvalidateCache`) только при изменении самой ячейки или любой ячейки, от которой она зависит.
2.  **Граф зависимостей:** Каждая ячейка хранит список тех, от кого она зависит (`dependencies`), и тех, кто зависит от неё (`dependents`). Это позволяет эффективно распространять обновления по цепочке (BFS/Queue).
3.  **Полиморфизм в ячейках:** Класс `Cell` делегирует поведение внутреннему классу `Impl`. Это позволяет cleanly разделять логику пустой ячейки, текстовой и ячейки с формулой без множества `if-else`.
4.  **Безопасное парсирование:** ANTLR настроен на режим "BailErrorStrategy", что позволяет мгновенно прерывать парсинг при первой же синтаксической ошибке и выбрасывать понятное исключение `FormulaException`.
